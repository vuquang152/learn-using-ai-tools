# 04 — Agent Configuration

## Thứ tự đề xuất

1. `01-repository-instructions` — `AGENTS.md`, `CLAUDE.md` và quy tắc theo thư mục.
2. `02-reusable-skills` — đóng gói quy trình có thể tái sử dụng.
3. `03-mcp-and-tools` — kết nối nguồn dữ liệu và công cụ bên ngoài.
4. `04-hooks-and-automation` — tự động format, lint, test và kiểm tra policy.
5. `05-permissions-and-sandboxing` — nguyên tắc least privilege.

Mọi cấu hình mẫu phải nói rõ phạm vi áp dụng, quyền cần thiết và rủi ro khi bật automation.
