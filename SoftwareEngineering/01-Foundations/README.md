## Definition of done

Bạn hoàn thành Foundations khi có thể:

- Phân loại task theo rủi ro và chọn mức tự chủ phù hợp.
- Cung cấp đủ context mà không nhồi toàn bộ repository vào prompt.
- Viết acceptance criteria có thể kiểm tra.
- Yêu cầu agent phân biệt fact, inference và unknown.
- Review diff và ánh xạ bằng chứng tới từng tiêu chí hoàn thành.
- Nhận diện secret, prompt injection và hành động vượt trust boundary.
- Đánh giá hiệu quả bằng chất lượng cùng thời gian chủ động, không chỉ bằng tốc độ sinh code.
