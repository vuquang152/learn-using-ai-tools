## Nguyên tắc thiết kế

- Workflow chung như explore, plan, implement, test và review chỉ được viết một lần ở phần lõi.
- Phần chuyên ngành tập trung vào stack, kiến trúc, công cụ kiểm chứng và những lỗi đặc thù.
- Backend Java/Spring là specialization được hoàn thiện đầu tiên.
- Claude Code và Codex là hai coding agent chính; không mở rộng thành catalog các công cụ tương tự.
- AI phải chạy build, test, lint hoặc kiểm tra tương ứng trước khi tuyên bố hoàn thành.
