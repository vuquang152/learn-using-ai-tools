# 07 — Projects

## Project lõi

1. Khám phá và viết architecture map cho một codebase chưa quen thuộc.
2. Tái hiện và sửa một bug có regression test.
3. Triển khai một feature từ requirement đến pull request hoàn chỉnh.
4. Refactor một module legacy mà vẫn bảo toàn behavior.
5. Xây CI workflow kiểm tra build, test và quality gate.

## Capstone ưu tiên đầu tiên

Xây hoặc nâng cấp một Spring Boot service có REST API, database migration, validation, authentication, unit/integration test, Docker và CI. Người học phải lưu lại requirement, kế hoạch của agent, các diff quan trọng, bằng chứng kiểm thử và retrospective.

## Rubric chung

- Correctness và mức độ đáp ứng acceptance criteria.
- Test quality và bằng chứng kiểm chứng.
- Security và xử lý dữ liệu nhạy cảm.
- Maintainability và độ phù hợp với kiến trúc hiện có.
- Khả năng giải thích các thay đổi do AI đề xuất.
- Phạm vi thay đổi có được kiểm soát hay không.
