# 05 — Vận hành và tối ưu công cụ AI

Phần này giúp kỹ sư phần mềm đưa công cụ AI vào công việc hằng ngày với mức chi phí, độ trễ và công sức review phù hợp. Có thể thực hành trên backend, frontend, DevOps, data pipeline, mobile hoặc game. Chọn một việc có tiêu chí kiểm chứng rõ như sửa lỗi phân trang, tìm nguyên nhân test fail, review một diff hoặc phân loại kết quả CI.

Đọc hai bài đầu rồi chọn bài tương ứng với công cụ đang dùng. Nếu chưa có tài khoản hoặc ngân sách API, bài thực hành có chế độ dùng dữ liệu mẫu và HTTP stub.

## Kết quả cần đạt

- Phân biệt được dung lượng context, token sử dụng, hạn mức gói, chi phí API và lượt chạy workflow.
- Chọn được model, mức suy luận và phạm vi công cụ phù hợp với một việc cụ thể.
- Giảm được đọc file, gọi API hoặc làm lại thừa mà vẫn giữ tiêu chí kiểm thử.
- Giải thích một lần tăng usage bằng dữ liệu quan sát được và đề xuất thay đổi có thể đo lại.
