# 01 — Claude Code

Claude Code là coding agent có thể đọc codebase, sửa file, chạy command và tích hợp với công cụ phát triển. Module này tập trung vào terminal workflow; các khái niệm instruction, permission và verification vẫn áp dụng khi dùng IDE, desktop hoặc cloud.

## Phạm vi

Sau module, bạn có thể thiết lập Claude Code trong một repository, kiểm soát quyền, cung cấp instruction bền vững, hoàn thành một task có kiểm chứng và biết khi nào cần mở rộng bằng skill/hook/MCP.
