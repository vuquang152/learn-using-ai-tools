# 02 — Codex

Codex có thể làm việc với repository qua CLI, IDE, desktop và môi trường cloud/worktree. Module tập trung vào local repository workflow, sau đó giới thiệu worktree và các lớp customization cần thiết.

## Phạm vi

Sau module, bạn có thể chọn đúng Codex surface, cấu hình repository instruction, vận hành sandbox/approval an toàn, hoàn thành task có verification, dùng worktree để tách công việc và chọn đúng lớp mở rộng.
