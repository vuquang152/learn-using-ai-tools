# Game Development

## Phạm vi dự kiến

Gameplay loop, scene/entity architecture, asset pipeline, editor tooling, input, physics, debugging, profiling và build/release.

Engine chính sẽ được xác định trước khi phát triển nội dung sâu; project phải đánh giá cả gameplay behavior và performance thay vì chỉ khả năng compile.
