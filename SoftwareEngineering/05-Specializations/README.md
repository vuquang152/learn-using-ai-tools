# 05 — Specializations

Các chuyên ngành được phát triển theo thứ tự ưu tiên dưới đây.

## 01 — Backend: Java/Spring

Trọng tâm đầu tiên: Java hiện đại, Spring Boot, REST API, validation, exception handling, Spring Data JPA, transaction, security, integration test, database migration, observability và performance.

## 02 — DevOps

Linux, shell, Docker, Kubernetes, CI/CD, Infrastructure as Code, cloud, monitoring, incident analysis và automation an toàn.

## 03 — Frontend: React

TypeScript, React, component design, state management, forms, API integration, testing, accessibility, performance và frontend debugging.

## 04 — AI Engineering

Model API, structured output, tool calling, RAG, embedding, agent workflow, guardrail, eval, observability, latency và cost.

## 05 — Data Engineering

SQL, data modeling, ETL/ELT, batch và streaming pipeline, orchestration, data quality, lineage và performance.

## 06 — Mobile

Sẽ chốt stack chính trước khi viết nội dung sâu. Phần chung bao gồm app architecture, state, API, local storage, testing, release và platform-specific debugging.

## 07 — Game Development

Sẽ chốt engine chính trước khi viết nội dung sâu. Phần chung bao gồm gameplay loop, scene/entity architecture, asset workflow, tooling, debugging và performance.
