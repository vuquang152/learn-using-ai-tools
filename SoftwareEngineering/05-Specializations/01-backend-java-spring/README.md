# Backend — Java/Spring

Đây là specialization được ưu tiên hoàn thiện đầu tiên.

## Lộ trình nội bộ

1. `00-roadmap` — mục tiêu, điều kiện đầu vào và project xuyên suốt.
2. `01-java-and-build-tools` — Java hiện đại, Maven/Gradle, dependency và test command.
3. `02-spring-boot-architecture` — layer, module boundary, configuration và dependency injection.
4. `03-rest-api` — contract, DTO, validation, mapping và error handling.
5. `04-persistence-and-transaction` — JPA, query, transaction, migration và database test.
6. `05-security` — authentication, authorization, secret và security test.
7. `06-testing` — JUnit, Mockito, slice test, integration test và Testcontainers.
8. `07-observability-and-debugging` — log, metric, trace, profiling và production evidence.
9. `08-performance-and-reliability` — concurrency, caching, resilience và load test.
10. `09-delivery` — Docker, configuration, CI và deployment checks.
11. `10-capstone` — Spring Boot service hoàn chỉnh.

## AI playbook ưu tiên

- Khám phá request flow từ controller đến database.
- Thêm endpoint từ API contract có sẵn.
- Tìm lỗi transaction hoặc N+1 query bằng bằng chứng.
- Viết integration test có database thật.
- Nâng dependency và đánh giá breaking change.
- Review security của authentication/authorization flow.
