# 03 — Core Workflows

## Thứ tự học

1. `01-explore-codebase` — tìm entry point, kiến trúc, data flow và quy ước.
2. `02-requirements-to-plan` — làm rõ yêu cầu, rủi ro và acceptance criteria.
3. `03-implement-feature` — thay đổi nhỏ, checkpoint và kiểm tra liên tục.
4. `04-debugging` — tái hiện, thu thập bằng chứng, xác định root cause và sửa lỗi.
5. `05-testing` — lựa chọn test level, viết test có giá trị và tránh test hình thức.
6. `06-refactoring` — bảo toàn behavior và kiểm soát phạm vi thay đổi.
7. `07-code-review` — review correctness, security, maintainability và test coverage.
8. `08-documentation` — tạo và đồng bộ tài liệu từ code đã được kiểm chứng.
9. `09-git-and-worktrees` — branch, commit, diff, conflict và làm việc song song.
10. `10-ci-cd` — phân tích pipeline, failure và automation an toàn.

Mỗi workflow sẽ có một ví dụ độc lập với ngôn ngữ và các biến thể áp dụng trong từng specialization.
