# 06 — Advanced

## Nội dung dự kiến

1. Quản lý context trong monorepo và codebase lớn.
2. Chia task và phối hợp nhiều agent.
3. Thiết kế human approval cho hành động rủi ro.
4. AI security và phòng chống prompt injection từ repository hoặc external content.
5. Evals cho coding workflow.
6. Theo dõi cost, latency và hiệu quả thực tế.
7. Xây reusable skills và internal developer platform hỗ trợ AI.

Phần này chỉ nên học sau khi đã hoàn thành ít nhất một specialization và một project thực tế.
