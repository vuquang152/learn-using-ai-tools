# 04 — Projects

## Project dự kiến

1. Xây trợ lý học một chủ đề mới từ tài liệu có nguồn.
2. Tạo báo cáo nghiên cứu có citation và phần kiểm chứng.
3. Xây workflow chuẩn bị báo cáo công việc hàng tuần.
4. Tự động phân loại và xử lý một luồng thông tin bằng n8n.

Mỗi project cần có brief, dữ liệu mẫu, milestone, rubric chấm điểm và phần retrospective.
