# 05 — Prompt Library

Thư viện này lưu các mẫu yêu cầu có thể tái sử dụng, được tổ chức theo mục tiêu công việc thay vì theo tool.

Mỗi mẫu phải giải thích:

- Dùng khi nào và không dùng khi nào.
- Những context người dùng phải bổ sung.
- Các biến cần thay thế.
- Định dạng đầu ra mong muốn.
- Cách kiểm chứng kết quả.

Prompt Library là tài liệu tham khảo, không thay thế cho phần Foundations.
